# CV Builder

Web application for creating professional CVs using LaTeX templates.
Users fill out a form and get a PDF-ready resume without any LaTeX knowledge.

## Tech Stack
- **Backend**: Spring Boot, PostgreSQL, JWT
- **Frontend**: React, TypeScript
- **LaTeX Service**: Python (FastAPI) + TeX Live in Docker
- **Message Brokers**: RabbitMQ (task queue), Kafka (event streaming)
- **Infrastructure**: Docker, Docker Compose

## Features
- User authentication (JWT)
- Multi-language interface (RU / EN)
- Multiple resume templates by categories
- Dynamic form generation from template schema
- Custom sections and drag-and-drop reordering
- Asynchronous PDF compilation
- PDF preview and download
